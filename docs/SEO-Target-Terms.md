# SEO Target Terms

**Created:** April 16, 2026  
**Status:** Active working reference  
**Purpose:** Keep a single internal record of which SEO terms K4 Studios is actively targeting, which URL is intended to carry each term, and which terms are already considered covered so we do not create redundant pages.

---

## Working Rules

- Consolidate overlapping terms onto one page when the search intent is naturally shared.
- Use standalone concept pages when the term is definitional or strategically important on its own.
- Use the heavier hybrid/editorial page structure only for multi-term clusters that need more semantic coverage.
- Keep single-intent pages on the cleaner existing layouts.
- If a term is already materially covered by an existing page, do not spin up a duplicate URL unless strategy changes.

## Update Protocol

When we add or change a target:

1. Add the term under the canonical URL that should rank for it.
2. Mark the page status as `Live`, `Planned`, or `Covered already`.
3. If a term moves to a different page, update both sections so the old target is not left behind.
4. If a term is intentionally absorbed into another page, record that here instead of creating a new standalone entry.
