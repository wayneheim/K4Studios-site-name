## Commercial Doorway Pattern

`/Western-Wall-Art` is the strongest current model for commercial-intent expansion. It differs from the "what is" definition pages because it leads with collector/buyer intent, curated proof images, print options, room/use context, FAQ, and internal paths into the galleries. That makes it a possible model for commercial pages where the searcher is closer to buying, decorating, collecting, or comparing print formats.

This pattern should not replace definition pages. It should sit beside them:

- Definition page = explains the category and helps AI/semantic classification.
- Commercial doorway = answers buyer intent and routes into image inventory.
- Gallery/proof page = shows the actual collection Google already likes.

The commercial doorway format should only be reused when the keyword cluster has clear buyer language such as "wall art," "prints," "art prints," "fine art prints," "decor," "for office," "for collectors," or a material/presentation term.
